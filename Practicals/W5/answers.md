Start
Gather flour, eggs, milk, butter, and sugar
Mix all ingredients together to make batter
Pour batter into a cake pan
Set oven to 400 degrees
Put cake in oven
Bake for 20 minutes
Check cake with a knife

While knife does not come out clean:
    Bake cake for a few more minutes
    Check again with knife

Remove cake from oven
Let cake cool
End
## Fizz Buzz

Start counting from 1 to 100

For each number:
    If number is divisible by both 3 and 5:
        Print "fizzbuzz"
    Else if number is divisible by 3:
        Print "fizz"
    Else if number is divisible by 5:
        Print "buzz"
    Else:
        Print the number

Stop after reaching 100
